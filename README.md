# collatz

Lean 4 での、コラッツ予想への「対数エネルギー関数」アプローチの形式化(Lean 4.24.0、Mathlib なし)。

## 状況

**コラッツ予想は証明できていません。** 未解決問題であり、`Collatz/Open.lean` の
`energy_drop_open` だけが `sorry` として残っています。それ以外はすべて証明済みです。

## 証明済み

| ファイル | 内容 |
|---|---|
| `Defs` / `Basic` | `step`, `iter`, `ReachesOne`, `Conjecture` と基本補題 |
| `Descent` | コラッツ予想 ⟺ すべての n>1 がいつか自分より小さくなる |
| `Energy` | 厳密なエネルギー恒等式 `2^b·x_k = 3^a·n + c`(a=奇数ステップ数, b=偶数ステップ数, c=「+1」の累積) |
| `Bounds` | 補正項の上界 `2c + 2^b ≤ 2^b·3^a`、エネルギー下界 `3^a·n ≤ 2^b·x_k` |
| `EnergyDescent` | `x_k < n ⟺ 3^a·n + c < 2^b·n`、負ドリフトの十分条件 |
| `Main` | `Conjecture ⟺ ∀ n>1, ∃ k>0, EnergyDrop n k` |
| `Sieve` | 剰余類 0 (mod 2), 1 (mod 4), 3 (mod 16), 11 (mod 32) で降下(手書き) |
| `Congruence` / `ClassDescent` | **一般定理**: `n ≡ r (mod 2^K)` で `r` が降下する(`b<K` の範囲で)なら、その類の全ての `n` が降下する |
| `Certify` / `Coverage` | 計算可能な証明書 `certify` と健全性。`descent_off_bad`: 未確定クラス以外はすべて降下。mod 4096 で未確定は 228 クラス(うち 0, 1 を含む) |
| `Verify` | `n ≤ 10^6` の全てが 1 に到達(降下基準 + 強い帰納法 + カーネル計算) |
| `Wall` | `2^K·m − 1` は最初の 2K ステップで降下しない。**停止時間は有界でない** |
| `Cycles` | 閉路のエネルギー収支。検証範囲に `{1,2,4}` 以外の閉路は無い |

`E(x) = log x` とすると、`EnergyDrop` は `E(x_k) < E(n)` の指数化形です
(コア Lean に `Real.log` がないため、不等式は指数化して整数で記述)。

## 壁

予想はエネルギー降下の問題へ厳密に還元されましたが、降下そのものは示せていません。

* 平均ドリフトは負(奇数 `+log(3/2)`、偶数 `−log 2`)ですが、個々の軌道で偶数ステップが
  十分多い窓が存在することは、軌道の算術的構造に依存し、これが予想の本体です。
* 剰余類ふるいで未確定のクラスの割合は K とともに減ります(mod 2^22 で約 2.2%、
  `#eval` による計算値)が、**ゼロにはなりません**: `Wall.stopping_time_unbounded` が示すとおり、
  `2^K − 1` の類は必ず残ります。有限の剰余検査では完結しません。
* 「ほとんど全ての n で降下する」(Terras の定理)の形式化には確率的な評価(二項分布の裾の評価)が必要で、
  このリポジトリでは未実施です。仮に形式化できても、それは密度 1 であって「全ての n」ではありません。
