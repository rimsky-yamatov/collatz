# collatz

Lean 4 での、コラッツ予想への「対数エネルギー関数」アプローチの形式化(Lean 4.24.0、Mathlib なし)。

## 状況

**コラッツ予想は証明できていません。** 未解決問題であり、`Collatz/Open.lean` の
`energy_drop_open` だけが `sorry` として残っています。それ以外はすべて証明済みです。

## 証明済み

| ファイル | 内容 |
|---|---|
| `Defs` | `step`, `iter`, `ReachesOne`, `Conjecture` |
| `Basic` | 反復の加法性、正値保存、`ReachesOne` の伝播 |
| `Descent` | コラッツ予想 ⟺ すべての n>1 がいつか自分より小さくなる |
| `Energy` | 厳密なエネルギー恒等式 `2^b·x_k = 3^a·n + c`(a=奇数ステップ数, b=偶数ステップ数, c=「+1」の累積) |
| `Bounds` | 補正項の上界 `2c + 2^b ≤ 2^b·3^a`、エネルギー下界 `3^a·n ≤ 2^b·x_k` |
| `EnergyDescent` | `x_k < n ⟺ 3^a·n + c < 2^b·n`、負ドリフトの十分条件 |
| `Sieve` | 剰余類 0 (mod 2), 1 (mod 4), 3 (mod 16), 11 (mod 32) で降下 |
| `Main` | `Conjecture ⟺ ∀ n>1, ∃ k>0, EnergyDrop n k` |

`E(x) = log x` とすると、`EnergyDrop` は `E(x_k) < E(n)` の指数化形です
(コア Lean に `Real.log` がないため、不等式は指数化して整数で記述)。

## 壁

予想はエネルギー降下の問題へ厳密に還元されましたが、降下そのものは示せていません。
平均ドリフトは負(奇数 `+log(3/2)`、偶数 `−log 2`)ですが、個々の軌道で偶数ステップが
十分多い窓が存在することは、軌道の算術的構造に依存し、これが予想の本体です。
参考: mod 2^16 で見ると 96.8% の剰余類は有限ステップで降下が確定しますが、
残りの類は 2^k とともに無限に残り続けます(ふるいだけでは完結しません)。
